# RAG From Scratch

A hands-on learning journey to understand and build Retrieval-Augmented Generation (RAG) systems from scratch.

This repository documents my daily progress, notes, implementations, and experiments while learning the complete RAG pipeline.

## About RAG

Retrieval-Augmented Generation (RAG) combines:

- Information Retrieval
- Embeddings
- Vector Databases
- Large Language Models (LLMs)

RAG retrieves relevant information from external data sources and provides it as context to an LLM for generating better responses.
